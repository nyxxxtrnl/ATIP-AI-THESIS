Mental wellness support

ATIP AI is a student project exploring personal wellness tools and consent-based coordination between clients and care professionals.

Open live thesis demo Run the app locally Project setup guide

What the project explores

Client wellness dashboard

A personal space for wellness results, activities, appointments, and messages.

Consent-based sharing

Clients choose whether to connect with an approved psychiatrist and can revoke access.

Care coordination

Connected accounts can coordinate appointments and exchange private messages.

Test data only: The GitHub Pages site is a static introduction. Open the live demo above to try the app. The free server may sleep when idle, and accounts or data may be erased when it restarts. Do not enter real personal or health information.

Try the app on your computer

Install Node.js 22.13 or newer, open a terminal in the project folder, then run:

npm install
npm start

Then visit http://127.0.0.1:3000/ in your browser.
